Data Flow

1
Web Request (Sync) — User browses the app
Browser → CloudFront → S3 (static) or ALB → ECS Fargate → RDS
2
Receipt Upload (Sync) — User uploads a receipt image
Browser → CloudFront → ALB → ECS (Presigned URL) → Browser → S3 Receipt Bucket (PUT)
3
Receipt OCR (Async) — Auto-parse receipt image
S3 PutObject Event → Lambda (Go) → Textract OCR → RDS INSERT
4
Subscription Scheduler (Batch) — Monthly auto-charge
EventBridge (1st of month) → Lambda (Go) → RDS INSERT (transactions)
5
Monthly Report (Batch) — Summary email
EventBridge (1st of month) → Lambda (Go) → RDS SELECT → SES email
